# bridge-mods

Carl's Claude app mods for **Bridge**, his engineering command board. Private.

| Mod | What it does |
|---|---|
| `bridge-test` | Throwaway test: `/bridge` opens a pane that reports its placement and width, draws an animated SVG ring, collapses to a band above the prompt. |

## Install

Desktop app: **+** next to the prompt → **Plugins** → **Add marketplace** → `convyares-FCSL/bridge-mods` → **Add plugin** → `bridge-test`.

Terminal session:

```
/plugin install bridge-test --marketplace convyares-FCSL/bridge-mods
```
