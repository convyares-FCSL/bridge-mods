# bridge-test

Throwaway test mod for Carl's Bridge companion pane. `/bridge` opens or closes a pane that reports where the app placed it (docked beside the chat or inline above the prompt), the width requested and the width granted, the viewport size and focus. It draws an animated SVG ring to check SVG and SMIL rendering, has Wider, Narrower and Collapse buttons, a link to the Bridge Previews page, and a band above the prompt while the pane is closed. `/bridge-width <columns>` requests a width. Delete once the real companion is built.
